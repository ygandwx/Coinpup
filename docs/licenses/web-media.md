# 网页图标和字体许可

网页构建将下列素材打包到同源静态目录。核对日期为 2026-11-27。

| 素材 | 固定上游版本 | 本地文件 | 许可 |
| --- | --- | --- | --- |
| 国旗与地区旗帜 | [flag-icons v7.5.0](https://github.com/lipis/flag-icons/tree/v7.5.0/flags/4x3) 的 4×3 SVG | `apps/web/public/assets/icons/flags/` | [MIT](flag-icons-MIT.txt) |
| BTC、ETH、XMR、USDT、USDC、TRX、SOL 和通用加密标记 | [cryptocurrency-icons v0.18.1](https://github.com/spothq/cryptocurrency-icons/tree/v0.18.1/svg/color) 的彩色 SVG | `apps/web/public/assets/icons/crypto/` | [CC0 1.0](cryptocurrency-icons-CC0.txt) |
| 微信、支付宝、PayPal、Wise、Stripe | [Simple Icons 16.38.1](https://github.com/simple-icons/simple-icons/tree/16.38.1/icons) 的 SVG | `apps/web/public/assets/icons/payments/` | 上游分发采用 [CC0 1.0](simple-icons-CC0.txt)，各图标另遵循[上游商标说明](https://github.com/simple-icons/simple-icons/blob/16.38.1/DISCLAIMER.md)及品牌指南 |

Simple Icons 16.38.1 的发布元数据未给这五枚图标单列许可。图标用于识别对应平台。品牌指南见 [微信](https://wechat.design/brand/main-brand)、[支付宝](https://global.alipay.com/docs/ac/website_hk/design)、[PayPal](https://newsroom.paypal-corp.com/media-resources)、[Wise](https://wise.design/foundations/logo) 与 [Stripe](https://stripe.com/newsroom/information)。

部署产物的旗帜目录也附有 MIT 版权与许可文本。机构标志的来源和用途见[机构标志来源](brand-logos.md)。国旗、币种符号及网络角标由应用组合。
