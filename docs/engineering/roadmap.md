# 实施路线图

需求基线见 `../product/requirements.md`，架构见 `../architecture/overview.md`，实际进度以 `status.md` 为准。T01–T12 为稳定任务编号；任务内部可拆子步骤，但只有满足全部验收条件才算完成。

## MVP 冲刺（2026-11-25 起）

用户 2026-11-25 确认：先完成 MVP，再补全同步、移动端和增强项，完成全部功能。每步按 [AGENTS.md](../../AGENTS.md) 的完整功能 PR 流程执行，最多一个开放 PR 包含迁移。合入后部署到仅本机的测试实例并用虚构数据验证；阶段汇报后继续推进。

### T02 的实施增量

以下是同一个 T02 内的开发顺序，不替代任务的整体放行条件。每个增量单独 PR，T03 的契约随实际服务共同实现。

| 顺序 | 交付 | 对应检查与边界 |
| --- | --- | --- |
| T02-1 | 不可变资产身份、精确数量、数值数据库边界 | A-07 底层精度；无账户余额或业务 API。见 ADR 0003。 |
| T02-2 | 主体、账本、账户、账户支持资产、分类模板复制及真实迁移 | 验证 A-01/A-02/A-03 的结构部分；同名对象独立，跨账本引用拒绝。资产目录约束禁止修改已引用精度。 |
| T02-3 | 原子分录、期初余额、手工收支、分类拆分、按账户/资产计算余额 | 验证 A-03 的 USD 75/EUR 90；期初不算收入，非法/不平衡过账整体回滚。前置业务操作 ID、审计字段和重复请求保护。 |
| T02-4 | 同币种转账、信用卡消费与还款 | A-04/A-06；本金不算费用，并发重复请求只入账一次，一侧失败则全部回滚。跨主体代付属于 T07。 |
| T02-5 | 换汇、实际转出/转入和手续费 | A-05/A-07；USD 898/EUR 90、BTC 0.89999，不用行情替代成交量。 |
| T02-6 | 更正、撤销、版本冲突与审计 | A-10 后端：支出 100 改为 120 后费用为 120；撤销恢复余额并保留历史。使用中的账户/分类归档不破坏引用；旧版本冲突与各次回执重放不覆盖现状。 |

完整 A-01 地区界面/证件、A-08 网页业务操作及 A-09 财务附件恢复仍需跨任务联调。只完成上表某个底层检查，不能把这些完整案例标为通过。

### T05 的实施增量

| 顺序 | 交付 | 对应检查与边界 |
| --- | --- | --- |
| T05-1 | 私有原件、两步可重试上传、同账本查重、流水关联、一致 bundle 恢复 | 实际流限额、归属隔离、不可变原件/回执、数据库与字节恢复；不宣称完成 OCR。 |
| T05-2 | 中英上传/下载/关联页面，桌面与手机重试流程 | A-01 证件原件与 A-08 照片上传；未知结果可恢复，不重复创建原件或费用。 |
| T05-3 | 本地文字提取/OCR worker、队列、资源限制、失败重试 | 中英文 PDF/图片真实样本，任务与草稿可追踪，未经确认不入账。 |
| T05-4 | 原件对照、候选金额与拆分类别、人工确认和阶段联调 | 重复确认只入账一次；票据、文件、流水及恢复关系完整。 |

T05-3 按 [ADR 0019](../architecture/decisions/0019-local-ocr-worker.md) 拆小 PR，依次合入：任务/草稿 schema 与历史保护 → 租约队列与任务接口 → 文字层/渲染隔离 → 本地引擎及冻结样本同机报告 → 草稿读取。队列与迁移拆为两个可独立评审目标；每个子步骤都不能代替完整 OCR 验收。T05-4 的确认事务技术决定先于实现，继续复用现有财务命令与 v2 摘要。

### T06 的实施增量

复用ADR0016/0022/0023的账户、业务引用、分录维度与期间保护；以下包按依赖逐步交付，每步可拆模型、服务/API、网页与恢复PR，不能用底层表存在代替完整业务验收。

| 顺序 | 交付 | 验收与边界 |
| --- | --- | --- |
| T06-1 | 往来单位与项目资料、归档/版本、项目维度 | ADR0024；账本隔离、旧引用兼容、变更通知、恢复；不产生分录。 |
| T06-2 | 业务草稿、分类/项目行、精确金额与资料快照 | ADR0026方案A；依次计价、模型/约束、服务/API、网页及恢复，草稿不入账。 |
| T06-3 | 有效单据确认、应收应付、不可变历史及v2回执 | ADR0039；含税收支、逐行应计与整单封存，保持旧五类命令；期间锁、并发及完整回滚。 |
| T06-4 | 实际收付款、部分/多对多/跨币种分摊、预收预付 | ADR0040、B-06至B-08；一次真实扣款，独立手续费，显式未分配余额；初始分摊原子提交、回填日期下界及开放期间；不做跨主体代付。 |
| T06-5 | 退款、贷项、更正/取消与已有付款来源关联 | B-05/B-11；拒绝不一致已结算直接修改，退款/冲销可追溯，OCR证据匹配不双记。 |
| T06-6 | 商业Invoice编号/中英PDF、周期草稿任务 | B-13/B-14；明确虚构验收，税率手工输入，不代发客户邮件；周期唯一键与恢复不重复。 |
| T06-7 | 双语经营工作区、项目收支/未结算展示及阶段联调 | B-05至B-14，中英桌面/375/320、原意图重试、完整bundle恢复；通过后继续T07。 |

T06-6的周期草稿只依赖T06-2，可在T06-3的产品决定待确认时先实现日历、实例、任务及恢复；它不触及确认、正式编号或入账。日历和稳定身份采用ADR0032，完整B-14仍须任务与网页验收。

## 并行与集成

T02/T03 的数据与接口由集成负责人协调。契约稳定后，网页、票据与经营模块按边界并行；报表建立在验证过的账务数据之上。每个 PR 更新状态、证据和下一步，重要取舍补充 ADR。
