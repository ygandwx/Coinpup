## T02-2 / T03 当前增量

设计见 [ADR 0004](../architecture/decisions/0004-owned-ledger-structure.md)。

- 迁移 `20261003_0003` 增加资产目录、主体、单主体主账本、账户、多资产关联、分类六张表；内置八种资产。
- 复合外键和不可变触发器保护资产精度、身份与账本归属；父分类必须先存在，拒绝跨账本/收支类型引用及循环创建。
- 主体创建与账本/分类复制同一事务；个人/公司和同名账户/分类彼此独立。支持显式原币与网络代币配置。
- `/api/v1` 结构接口采用会话所有者、Origin/CSRF 写保护、有界列表、UUID 和 `expected_version`；旧版本返回 409。
- 归档保留记录，主体归档暂停账本写入，恢复后可继续；账户资产移除采用停用关联。尚无删除、分类移动或完整同步。
- 公司资料按已确认地区/类型做输入一致性校验，支持自定义字符串资料；暂无地区网页/证件/自动期限推算。
- 备份验收扩展到全部应用表的精确文本比对，并通过真实服务重新读取虚构个人/公司、多资产账户、分类和归档版本。附件尚未实现。
