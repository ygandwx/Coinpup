## T02-3 / T03 当前增量

设计见 [ADR 0005](../architecture/decisions/0005-atomic-posting-and-receipts.md)。

- 迁移 `20261003_0004` 增加稳定业务操作、不可变分录、数量行、唯一期初标记和持久回执五张表。
- 提交时逐资产配平并封存；禁止修改、删除或随后补加分录行；复合外键限制所有归属。
- 期初不算收入，支持负数期初；手工收支可按分类拆分，保留交易日和业务归属日；余额按账户/资产精确求和。
- 新财务 POST 需要会话、Origin/CSRF 及 `Idempotency-Key`；同账本同键同验证后请求体返回原 201 回执，异体 409；金额文本 `1.0` 与 `1.00` 是不同请求。
- 已成功请求在主体/账户归档或资产停用后仍可重放；新命令被拒绝。余额保留归档账户、停用关联和零余额，附状态标志。
- 应用 SQL 绑定前检查 Amount 与实际行资产/目录一致，不经浮点数或静默舍入；数据库独立检查行精度、角色、配平和期初对应。
- 备份夹具增加真实期初、拆分收支、ETH/USDC/JPY 精确数量；恢复后重读余额，重放原回执不得改动数据库，并检查封存仍阻止补行。
