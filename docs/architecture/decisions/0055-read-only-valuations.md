# ADR 0055：保留原币和报价依据的只读估值

状态：采用。依据：[C-12、P-02](../../product/requirements.md)、[C-02 至 C-04](../../product/acceptance.md)、[ADR 0003](0003-exact-asset-amounts.md)。

## 背景

100 EUR 的历史费用按 1.10 折为 110 USD，当前余额按 1.20 折为 120 USD。两个结果都不能更改 100 EUR；USDT 与 USD 也不能只凭代码视作同一种资产。

## 决定

- 默认保留各原币小计。选择 USD、GBP、EUR、HKD、CNY 后才估值。费用默认交易日历史报价、账户余额默认最新报价；可以显式切换。报价方向固定为“一单位指定原资产对应多少展示币”，匹配完整资产身份、网络和精度。相同资产无需报价，不构造虚假的市场来源。
- 估值使用直接币对。来源提供时点时，保存带时区的实时报价时点。仅提供参考日的来源按日保存，并保留独立的获取时点。缓存展示原时间。原始行情写入所有者独立的不可变观察表，重复获取相同事实保留首次获取证据。手动修正沿用既有价格表及不可变审计，同一币对和日期优先采用手动价格。
- 原数量使用已有的 `Amount`。报价是有界的正十进制字符串；先精确相乘，保留展示币最小单位的有理数结果和所用报价，最后展示时才舍入到展示币精度。半个最小单位向远离零方向舍入，正负对称；合计先累计精确值，再舍入一次。资产处于停用状态不抹去其历史身份。
- 无可用报价时返回“不可估值”和原数量，不用零填充；含缺价行的报告不能把已知部分冒充全部合计。估值与账务写入、结算回执、期间锁、账本基准币和已封存快照相互独立。此计算不提供跨账本授权：筛选和报告必须先按实际所有者、主体和账本范围读取数据。

- 指定价格日只使用当天证据。历史收支使用交易日，历史余额使用明确的截至日期。最新口径按币对取最近一日，再优先采用手动价格。同一来源时点有不同报价且无手动价格时，标为缺价并保留所有观察。

## 影响

分开验收直接报价运算、报价来源与历史/最新选择、持久缓存与人工更正、只读报表与双语界面。使用虚构的直接报价验证极小金额、负值、不同网络、稳定币脱锚、缺价和汇总舍入。跨主体报表的内部交易识别必须依赖已经验证的关联，不使用同额同日启发式。

## 备选方案

用浮点行情乘单笔金额会先丢失最小单位精度；逐行舍入再求和会改变汇总。把未知资产按零或把稳定币按一比一显示，都可能让使用者误读账面余额。
