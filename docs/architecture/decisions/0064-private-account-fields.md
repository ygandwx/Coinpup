# ADR 0064：账户私密字段的认证加密

## 背景

银行卡号只在所有者主动查看时展示。平台和钱包资料可由所有者编辑。数据库管理员、取得普通 PostgreSQL dump 的人、恢复工具及移动端不需要这些字段的明文。

## 决定

| 数据 | 存储与读取 |
| --- | --- |
| 信用卡、借记卡完整卡号 | API 加密后写入独立列。普通账户读取只判断是否已保存；有会话及 CSRF 保护的显式查看接口核对账本、账户和卡类型后解密。 |
| 自定义平台名、平台 UID、邮箱、备注；各币种的充值地址、Memo/Tag、标签 | 各字段独立加密，所有者网页继续按原权限读取和编辑。自定义平台唯一性用单独派生密钥的 HMAC-SHA-256，输入含账本和规范化名称。同一账本内的相等性是唯一索引所需的信息。 |
| 旧账户详情及自定义键值 | 整个私有 JSON 加密，包括持卡人、有效期、关联银行账号、IBAN、支付账号、旧钱包地址及未知键值。经格式核实的卡号后四位另存于公开详情，供遮罩使用。移动端的卡摘要只交付后四位和有效期。 |
| 目录和账务事实 | 机构目录 ID、托管模式、币种、网络、代币合约、资产精度、余额、账户显示名与业务 ID 继续用于选择器、凭证、报表与同步。代币合约地址识别资产；用户的充值地址有独立加密列。显示名是用户指定的账务标签，录入时应使用可显示的名称。 |

字段使用 `cryptography` 的 AES-256-GCM，每次生成 96 位随机 nonce。信封携带格式版本和密钥 ID。认证附加数据包含版本、密钥 ID、表、字段、账本、账户及适用的资产 ID。自定义平台索引密钥从该部署密钥使用有域标识的 HMAC 派生。新格式有独立版本；历史迁移使用冻结的 v1 协议。[认证加密文档](https://cryptography.io/en/latest/hazmat/primitives/aead/#cryptography.hazmat.primitives.ciphers.aead.AESGCM)

迁移保存一个加密的已知验证值。API 启动时以独立密钥解密核对；修改密文或记录上下文会使对应读取失败。错误只返回通用诊断。数据库、SQL、日志和 bundle 无需密钥材料。

## 影响

移动变更日志持有对象 ID、版本、动作和游标。设备财务命令、回执和充提引用用账户、资产 ID 与金额，财务报表及其导出使用账务显示名。升级保持这些历史和版本。字段级加密范围是账户资料；用户上传的原件、其他业务自由文本及旧归档按各自的访问和备份规则管理。输入接口拒绝 CVV、PIN、私钥及助记词字段。

## 备选方案

仅做磁盘加密无法保护导出的数据库。对账户标识做普通哈希会暴露可枚举值，确定性加密也会把字段间的相等性暴露给取得 dump 的人。单独的密钥托管和限于一项业务约束的索引将此信息限制在所需范围。
