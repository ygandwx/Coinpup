## 新 ADR 模板

使用下一个可用编号和简短主题文件名。新 ADR 不超过 80 行，仅写稳定设计，不写任务进度、命令结果、测试数量或 CI 运行记录。

```markdown
# ADR NNNN：标题

## 背景
需要解决的具体问题及约束。

## 决定
选定方案、适用范围及必须保留的不变量。

## 影响
对接口、数据、运行方式和后续工作的影响。

## 备选方案
比较的替代方案及未采用的原因。
```
