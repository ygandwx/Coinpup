# ADR 0053：项目收付款的归属与日期

状态：提议。依据：C-06/C-07、B-06/B-08/B-12、ADR0040、0043、0049、0052。

## 背景

同一笔真实付款可先预付、以后才明确分到多个项目；分摊退回后资金仍可能在原账户之外。项目收付款不能以应收应付账户变动冒充，也不能把整笔有多个项目的付款计给每个项目。

## 决定

- 在项目报告按原付款交易日选取期间，只统计截至报告结束日已显式归入项目的收款与付款本金，分别使用付款资产。选定日期含首尾。归属来自对应项目的封存单据侧分录；数量来自同一应用或退回凭证的付款侧预收/预付行。保持两侧账本及付款身份，跨币不估值。
- 每个应用或退回成员拥有独立操作。按不可变操作到付款的映射关联其已封存日记账，累加截至结束日的原始、冲销、替代本金；旧版本不能重复匹配。中途被移除、替换或取消的成员，按其真实冲销记载。明确退回是资金的项目归属变化，不是发生了一笔反向银行交易。
- 未应用的本金没有项目；后来应用的预收预付不将原付款日期改到应用日。银行实付/实收、分摊调整、未分配资金及退款流水仍可按原付款/退款查看。未归到项目的手续费不计入本列。仅关联一个或多个退回作为退款证据不能证明这笔退款在各项目之间如何分配，不猜测金额。
- 新增 `attributed_received` 与 `attributed_paid` 两个原币字符串；已有经营期间收支、期末未收/未付保持不变。一种付款币即使没有任何本币业务分类或未结余额，也可因明确归属的资金数量而单列。项目列不是银行流水净额；无统一换汇加总。

## 影响

B-12 可在同一项目看到收入1000、成本400、结余600、已归属收款600/付款300、期末未收400/未付100。不同公司的同名项目独立。验证跨币、后期退回/更正/取消以及未分配项目部分，均不另记资金。

## 备选方案

直接合计账户流水会重复多项目付款；只按当前单据币种或分摊生效日展示，则会错误替代付款原币或日期。
