# ADR 0017：结账截止日与期间重开

- 日期：2026-10-04
- 状态：已采纳。
- 关联：[OPT-25](../../engineering/optimization-plan.md)、[ADR 0008](0008-operation-revisions-and-cancellation.md)、[ADR 0014](0014-versioned-command-hashes.md)、[ADR 0015](0015-ordered-change-log.md)。

## 背景

更正和取消目前以原交易日、原归属日追加精确冲销，更正的替代凭证使用请求中的日期。历史封存凭证不可改写，但追加分录仍会改变旧期间汇总；仅展示历史不能防止已出具报表的期间悄然变化。

用户已确认：新分录任一日期进入已结账期间时拒绝；更正、取消涉及已结账期间时也拒绝，必须先显式填写理由重开。每个账本可选择不结账，未结账账本不受期间限制。

## 决定

采用以下规则：

- 每个账本独立保存 `closed_through: date | null` 与正整数 `version`；空值表示未结账，可一直不启用结账且保持原有入账、更正、取消行为。截止日包含当天，不依赖公司注册地、时区或其他账本状态；已结账后改为空值仍须执行带理由的重开，不能绕过审计。
- 关闭、提前截止日、后退截止日或解除关闭均提交预期版本与非空理由。版本每次加一，追加不可变审计：账本、执行人、记录时间、原/新截止日、动作与理由；向前关闭不能覆盖既有重开记录。
- 新增入账只要交易日或归属日任一个 `<= closed_through`，拒绝并返回稳定的 `409 period_closed`；缺省归属日按现有规则解析后检查。包括期初、收入、支出、转账、换汇和费用，不能只检查报表当前选择的日期口径。
- 更正同时检查被冲销凭证的两个日期和替代凭证的两个日期；取消检查被冲销凭证的两个日期。原日期已关闭时，把替代日期改到开放期间也不能绕过限制。
- 用户先带理由缩小截止日或解除关闭，再执行更正/取消；完成后可重新结账。重开改变期间状态，不修改历史凭证、原金额、原日期、封存标记或已有回执。
- 财务命令完成身份与账本权限校验后，先匹配并重放既有回执，再执行新的期间检查。v1/v2 历史成功回执不因随后结账、重开、归档或当前版本变化而失效；重放不追加分录或审计。
- 新写事务顺序为已有提交顺序咨询锁 → 账本锁 → 完成归属校验并优先重放已有回执 → 仅回执未命中时校验关闭状态/版本 → 主体锁 → 排序资产锁 → 原入账流程。读取关闭快照可提前，任何会拒绝命令的期间检查只能在回执未命中后执行。关闭/重开也先咨询锁再账本锁，采用相同串行边界，禁止先查日期后另起事务写入。
- 关闭命令使用自己的幂等回执与预期关闭版本；财务命令检查锁内最新关闭状态，不强制向既有财务请求增加新字段。关闭先提交则旧日期入账被拒绝；入账先提交则关闭包含这次已提交事实。
- 报表按账本、日期口径与选定区间标注“已结账 / 未结账 / 部分结账”，记录截止日、关闭版本和生成时间；跨账本汇总保留各账本状态。曾重开的区间显示重开时间、理由与版本，即使再次结账也可追溯。
- 如保存或发布报表，保留原报表快照及其关闭版本；重开后标记该快照所依据期间已重开，重新生成另存新版本，不覆盖旧报表。此锁定是账务控制，不代表自动完成任何地区的法定申报。

## 影响

- 后续实施时新增账本关闭状态、理由审计和关闭命令回执的迁移，历史账本默认开放，是否结账由各账本独立选择。既有财务回执关联业务，不能直接当作关闭命令回执而伪造财务业务。
- 新增关闭状态读取、关闭/重开命令及审计查询接口；请求带预期版本、理由和幂等键，响应给出当前关闭状态与版本。过期版本返回冲突；精确路由、模型与错误字段在实施 PR 固化到 OpenAPI。
- 拒绝旧日期入账是明确的新行为，需要网页说明、冲突提示与重开入口。现有更正/取消响应、金额编码、原始摘要、完整逆向行与余额计算保持不变。
- 关闭状态参与变更通知，扩展同步实体类型及版本规则；不提前实现移动端。备份恢复覆盖关闭状态、审计、关闭回执与报表快照；存在关闭审计时降级应拒绝丢弃历史。
- 验收覆盖不结账账本行为不变、独立账本互不影响、截止日前/当天/后一天、两个日期分别越界、默认归属日、费用、原关闭但替代开放的更正、取消、带理由重开再关闭以及过期版本。
- 验收覆盖关闭与入账并发两种提交顺序、整笔回滚、余额及历史行不变、关闭命令未知提交后原键重试、v1/v2 旧财务回执跨关闭/重开重放，以及汇总状态、重开标记和恢复后审计完整性。

## 备选方案

- 仅警告（未采用）：录入更自由，但原期间数字仍会变化，不能满足本次选择的期间保护。
- 把冲销和替代记到开放期间（未采用）：需要新的期间调整语义及数据库约束，现有 ADR 0008 和冲销校验要求原日期一致；保留原更正/取消语义，不采用自动改期。
- 完全禁止重开（未采用）：错误无法通过当前更正链修复；采用允许带理由重开并保留完整审计。
