# ADR 0052：按项目读取经营收支与未结算金额

状态：提议（T06-7技术细化）。关联：需求P-03，验收B-05至B-08，ADR0003、0022、0024、0039、0040、0046及0050。

## 背景

一笔业务可能先确认经营收入或费用，后来发生多次收付款、分摊、贷项和更正。项目不能用当前单据总额加银行流水统计；这样会重复记账，也会丢失历史更正及跨币种的维度。

## 决定

- 首个读取按已授权账本的单个持久项目ID及必填起止业务日期（含首尾）查询。归档项目仍可读取；不把旧的无项目分录、其他账本的同名项目或预付款按比例摊入该项目。
- 在同一只读快照内仅使用已封存且项目、账本匹配的分录。经营收入为所选归属期间收入分类行的符号取反之和，经营成本为费用分类行的符号和，结余为收入减成本。既有单据按确认的含税金额入账；不重新计价，不另加税额。显式冲销和替代按各自保存的归属日参与；不只看操作的当前凭证。
- 期末未收和未付是截至所选结束日（含）的单据控制余额：分别汇总应收客户账户的原符号与应付供应商账户的反符号，且必须有同项目的单据及行维度。按已保存的业务归属日结算；开始日期不裁剪期初未结余额。归属日与结算日顺序导致的期间反向余额保留符号，不取绝对值或钳制。此为按当前已知封存事实重算的业务日期报告，不声称复原过去某时刻系统所知。
- 分摊和退回改变对应单据余额；不再计作经营收入/成本。付款侧未应用预收预付、跨主体往来和未归入项目的手续费不虚构项目归属。退款对单据余额的影响以显式已过账的证据变动为准。开票编号及PDF不会产生经营分录。
- 按完整资产身份独立分组，以该资产精度返回十进制字符串；不合计不同资产，不估值、不净抵应收与应付。未发生期间活动且期末已结清的零行可省略。累计列超出当前金额契约明确返回范围错误，不截断、不改精度。结果按资产身份稳定分页。
- 不新建事实表、余额缓存或迁移，不写业务通知或回执。API需要现有会话与账本读取授权，网页按所有者、账本、项目、日期及页切换隔离请求。项目名称用于展示，不作为筛选键。

## 影响

经营期间的流量与期末未结余额分别标明日期含义。验收覆盖上期应计、本期部分应用、结清、贷项和更正/取消、项目及账本隔离、归档、不同资产及小数精度；项目报告只是T06-7的一部分。

## 备选方案

按当前草稿/单据加总无法区分已封存和未入账事实；按银行变动分类会遗漏应计、混入未应用资金。另建报告事实表需要独立版本与恢复证明，现有维度已足以查询。
