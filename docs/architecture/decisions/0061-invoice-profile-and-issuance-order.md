# ADR 0061 商业发票配置与发行顺序

状态为提议（T06-6 技术细化）。承接 [ADR 0051](0051-commercial-invoice-issuance.md)。

## 背景

公司发行配置可以更新。每次预留必须永久绑定审阅过的配置、号码、原件身份和前次发行，才能在中断或恢复后继续同一次发行。

## 决定

- 配置沿用主资料的当前版本，每次修改或归档推进一次。预留快照冻结完整配置及 Logo 字节身份。Logo 只能选择当前账本已审阅的私有图片。
- 公司序号取账本历史预留的最大整数加一，从 1 开始。在咨询锁和公司账本锁内取得下一号，数据库校验连续性、已审阅前缀和补零位数。账本与序号的唯一索引支持取最大值及竞争保护。完整号码仍需唯一。到达 BIGINT 上限后返回序号耗尽。
- 发行键与已有财务命令共享账本作用域。预留提交时永久占用该键。成功回执完成后按原意图和正文重放。
- 每份单据的预留形成单链。首条无前驱，后续只关联本单据的最新预留，并绑定更高的单据版本。前次处于待完成状态时仍保留前驱及其原意图。每个实际预留占用一个新号码。

## 影响

更新配置、渲染中断或恢复空库后，已预留号码和绑定事实可继续使用。既有编号、配置快照、双语原件和版本关系继续可查。对外发行入口依赖以上约束完整落地。

## 备选方案

另存可修改的计数器会增加需要同步恢复的状态。复用不同命令类型的键会让未知提交的归属变得不确定。同一单据允许多条前驱链会失去明确的再发行顺序。
