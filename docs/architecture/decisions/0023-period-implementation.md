# ADR 0023：可选结账的事务与接口实施

- 日期：2026-10-09
- 状态：已采纳（ADR0017的技术细化，无新增产品选择）。
- 关联：[ADR0017](0017-closing-periods.md)、[ADR0015](0015-ordered-change-log.md)。

## 背景

关闭期间需要与现有财务事务串行，同时保证历史成功回执先于当前状态重放。
现有财务及OCR绑定事务已按咨询锁、账本、主体、资产顺序获取部分锁；不得为了调整检查位置倒置或重复建立事务。

## 决定

- 使用独立 `ledger_periods`、`ledger_period_audits`、`ledger_period_receipts` 表；全部接入变更日志。不存在状态行表示开放、版本1，首次操作产生版本2；不修改旧账本响应或回填旧账本。
- 状态身份固定、版本逐次增加；审计和回执不可更新删除。数据库延迟校验状态、连续审计链及每条审计的独立回执，同事务缺任一项即拒绝。存在数据或变更历史时禁止降级。
- `GET /api/v1/ledgers/{ledger_id}/period` 读取状态；`GET .../period-changes` 分页读取审计；`POST .../period-changes` 提交 `action`、必填可空 `closed_through`、`expected_version`、非空理由及幂等键。
- `close` 必须给出非空且不小于当前截止日的日期；`reopen` 必须从已关闭状态显式缩小截止日或改为空。不能把日期后退隐含为普通修改。重复截止日可作为带理由重新确认，仍产生新版本和审计。
- 关闭命令使用独立v2摘要：固定路由、账本、动作域及原始JSON；永久保存响应。先校验账本归属并重放已有回执，再验证当前状态、预期版本和主体状态。同键不同原意图返回冲突。
- 所有写操作先取得已有咨询锁，再锁账本；期间检查在原回执未命中后、写入前执行。已持有主体/资产锁的现有财务/OCR绑定路径保留锁序，读取期间状态不新增锁、不另起事务；这是对0017示意步骤的保守适配。
- 新入账检查两个日期；更正检查原凭证和替代凭证两个日期；取消检查原凭证两个日期。数据库新增凭证插入检查作为防线，不改现有形状、完整冲销和历史链函数。
- 网页关闭/重开使用独立内存待确认意图，未知提交保持原键和原JSON，401后只允许同用户继续；不扩展旧财务命令字段。
- 提供选定区间关闭状态和最近重开元数据的只读基础。T08报表、已发布快照仍待其任务实施，本轮不创建报表系统。

## 影响

迁移、财务/API、网页恢复验收分包实现；公开关闭命令前必须具备财务期间检查。备份验证恢复状态、审计及原回执重放；所有旧财务回执和未结账账本行为保留。

## 备选方案

不在旧账本表追加响应字段，不借用财务回执伪造业务，也不通过回写或自动改期调整历史。
