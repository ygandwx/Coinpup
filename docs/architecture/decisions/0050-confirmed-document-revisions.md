# ADR 0050　已确认经营单据的整单更正与取消

- 状态为提议（T06-5 技术细化）。
- 依据为 P-03、P-06、B-05、B-11、B-13，以及 ADR 0008、0014、0015、0026、0039、0040、0043、0046 至 0049。

## 背景

确认后的 Invoice 或供应商账单可以有零金额行，并可按不同归属日分别确认收入或费用。原确认回执列出全部非零行对应的应计操作和凭证。分摊、退回、贷项、私有文件及正式发行记录都可能引用其中的身份。修改确认快照会破坏旧回执，也会使结算容量取错版本。

## 决定

- 修订绑定授权账本、原单据和已确认的单据版本。首次预期版本取原确认回执中的 document_version；它随草稿编辑次数变化。每次成功恰加一。单据及确认身份、主体、Invoice 或账单种类固定。取消终止单据。普通草稿写接口及普通子操作修订入口继续执行原保护。
- 更正提交原因、完整替代表头和 1 至 200 行有序计价输入。沿用草稿行身份、数量、单价、折扣、税率、分类、项目和归属日契约；服务端按 ADR 0026 逐行重新计算净额、税额与含税额，整单含税额为正。未改变的引用保留已审阅快照。改变引用时核对新资料与版本，冻结用户实际审阅的替代事实。
- 原表和原确认快照永久可读。每版记录有序行与稳定行身份。保留有金额的行沿用应计操作，完整冲销此前正常凭证，写入替代凭证。被移除或变为零的有效行完整冲销并终止该操作。新出现或从零变为正的行建立新 v1 操作。已终止的操作保持终态。零值行有可追溯的版本事实，不创建零分录。
- 复制旧封存分录的日期、金额、资产、账户和各维度作冲销。按新版本开票日及逐行归属日写替代应计，每资产分别配平。旧、新影响日期均需开放，包含零值行。新入账需有效的资产、资料及控制账户。取消和纯冲销保留已停用旧引用。实际付款与退款各自保留资金分录。
- 写事务取得咨询锁、账本和主体锁、按稳定顺序锁定新旧资产，再读取同一新快照。按候选源行批量核对当前有效应用、明确退回、贷项净额及税额。用单据侧资产最小单位计算每一行。净应用加有效贷项含税额不得超过替代行含税额；贷项净、税还须分别在替代净、税以内。移除、归零或取消按该行零容量核对。历史分摊已全部退回、贷项已取消时仍保留这些历史的可读性。
- 已有效使用的来源必须继续满足往来、资产、行身份、分类/项目、应计与结算日期等实际关联约束。变更会留下不一致的有效分摊或贷项时明确拒绝，报错前后整库一致。操作者显式修订相关业务后，可重新审阅、用新意图提交。每笔资金、贷项与证据有各自的永久回执。
- 组版本、事实、凭证、操作头、同步通知和固定 200 同事务提交。数据库复合外键及延迟约束证明同账本单据、前驱和完整行集，拒绝孤立推进、非连续版本、源行串用与终态复活。新创建的行应获得可由经营引用及分录验证的稳定身份；验证原确认时始终读取原版成员。
- 沿用授权后先核对永久幂等键与 v2 原 JSON 摘要的顺序。历史 201、逐版 200、当前单据、历史目录和固定单版详情分别可取。重放使用原回执，适用于后续修订、归档及关闭期间。新分摊、退回容量、贷项、未结余额与阶段报表按所需版本读取，避免把原创建快照当成有效现状。读端使用同一只读快照。
- 按公司规则正式发行商业 Invoice 时绑定确切的有效单据版本。更正后再发行取得新号码并关联旧发行，旧号及两种语言 PDF 原件永久保留。该发行操作独立于单据修订；相同发行意图重放须返回同一发行及文件。

## 影响

用虚构账单 100 和已应用 100 验证直接改为 50 被拒绝。显式退回后再验证合法替代、未结金额及历史。验收覆盖不同日期、零行与正金额互换、逐项舍入、已取消和仍有效的贷项、跨币种单据侧数量、不同账本、同时分摊/贷项及同版本竞争。完整空目标恢复核对各版事实、各表、原文件和通知游标，逐版重放零写入。双语网页显示当前和不可变原版，未知结果始终使用已审阅的原正文和键重试。

## 备选方案

原地编辑草稿/确认快照会改变已经交付的证据。由修订命令级联改写分摊、贷项或退款会执行用户未明确审阅的资金或来源变更。逐行独立提交无法在中途失败时保持完整单据、结算和历史一致。
