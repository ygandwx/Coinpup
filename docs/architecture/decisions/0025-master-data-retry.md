# ADR 0025：资料编辑的未知结果与核对

- 日期：2026-10-09
- 状态：已采纳（ADR0024稳定身份与版本协议的网页技术细化）。
- 关联：[ADR0024](0024-business-master-data.md)、[API约定](../api-conventions.md)。

## 背景

往来单位与项目资料可版本化修改，但没有财务命令的永久回执。网络中断后不能把“记录存在”当成本次修改成功，也不能自动替换UUID或expected_version。

## 决定

1. 网页使用专用内存控制器，提交前冻结所有者、账本、资料种类、UUID、方法与完整请求JSON。一个意图只有一次在途请求；未知结果只重试原请求，CSRF使用当次会话值。不写浏览器持久存储，不占用财务回执空间。
2. 成功响应必须匹配作用域、身份、预期的新版本和本次提交字段；名称按服务器的规范化规则比较，其他文本原样比较。响应无法验证时保持未知状态。
3. 未知创建遇到重复ID时，读取同账本同ID核对；版本1且字段与原创建一致才显示已核对成功。若记录已变更或字段不同，展示版本冲突及当前资料，要求人工核对；不覆盖它、不自动生成新UUID。读取失败仍保留原意图。
4. 更新返回版本冲突时保留草稿和原版本。此前结果未知时，只有读到同账本同ID的更高版本，才解除待提交锁并进入待核对冲突状态：更高版本会拒绝所有迟到的同版本更新。不能声称此前提交一定失败或成功。
5. 用户显式载入当前资料后才开始新的编辑意图；此动作可以替换预期版本，普通重试不能。归档和恢复同样走此流程，不使用独立的绕过路径。
6. 401隐藏私有内容，保留原所有者的内存意图，同用户重新登录后手动恢复。更换用户或显式退出清理意图；代际标记隔离旧请求的迟到响应。
7. 未确认的提交锁定主体切换/相关导航并提示关闭页面可能失去内存意图；语言切换只改显示。确认或已核对冲突可以结束意图，不阻止用户继续其他工作。
8. 资料模块不产生分录；已确认经营单据的展示快照不会随资料更改而变化。单据确认与结算继续使用各自永久财务回执协议。

## 影响

控制器与API封装先独立验证，再接中英资料界面。覆盖重复点击、响应丢失、创建重复ID核对、未知更新冲突、更高版本核对失败、401/同用户恢复、用户切换和迟到响应；网页联调覆盖桌面、375及320宽度。

## 备选方案

只根据GET中存在记录判成功会混淆其他编辑；自动换版本重试会覆盖并发改动。为所有资料再建永久财务式回执超出当前协议需要；采用稳定UUID、受控版本与显式核对。
